# Ecommerce-app

A mini e-commerce web app built with **Node.js**, **Express**, **MongoDB**, and **JWT authentication**.  
Features include product listing, cart, checkout, and user login.

## 🚀 Features
- User registration and login with JWT
- Product listing and search
- Shopping cart functionality
- Secure checkout process
- Order management

## 🛠️ Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Afrin210107/ecommerce-app.git
2. Navigate into the folder:
   ```bash
   cd ecommerce-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   ## ▶️ Usage
Start the server:
```bash
npm start
